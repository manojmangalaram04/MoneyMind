# MoneyMind — Personal Finance Management

A fully editable, responsive finance dashboard built with HTML, CSS and vanilla JavaScript.

## Run
Extract the ZIP and open `index.html` in a modern browser. No build step, server, database or API key is required. For development, open the folder in VS Code and use Live Server.

## Working features
- Create, edit and delete income/expense transactions.
- Categorise transactions, set dates and add notes.
- Filter the dashboard by month.
- Live summary cards, savings rate, spending donut and cash-flow chart.
- Create, edit and delete category budgets.
- Export the selected month's transactions as CSV.
- Light/dark theme toggle and responsive mobile navigation.
- Persistent browser storage using localStorage.
- Reset demo data to the initial sample dataset.

## Files
- `index.html` — interface and dialogs.
- `styles.css` — layout, responsive styles and themes.
- `app.js` — application logic, chart drawing and local persistence.

## Data and privacy
Your data is saved in the current browser's localStorage and is not sent to a server. Clearing browser data may remove it. The sample transactions are illustrative; use the reset control beside the profile to restore the original demo data.

## HCI principles demonstrated
Visibility of system status, feedback, consistency, recognition rather than recall, error prevention, minimalist design, and responsive accessibility.
